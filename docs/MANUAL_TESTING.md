# Manual Testing

1. Start dev server with `npm run dev`.
2. Open `/` and confirm the six-step Command Center is visible.
3. Open `/event-radar`, switch 7/14/30 days, filter event type/theme, hide overheated and low-confidence events.
4. Open `/trade-plan`, generate a plan, verify shares/cost/risk reward calculations, export Markdown, and add a journal note.
5. Open `/portfolio`, add a manual position, verify exposure and alerts update.
6. Open `/risk-center`, confirm Event/Position/Portfolio/Behavior risks render.
7. Open `/journal`, add an entry and confirm behavior metrics update.
8. Open `/reports`, switch report formats.
9. Open `/settings`, export JSON, import JSON, clear demo data, reset local data.
10. Open `/data-center` and confirm all sources are marked Demo.
